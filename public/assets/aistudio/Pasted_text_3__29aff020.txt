Executive Summary
Where Pricelog Executes:
Pricelog's Plaisio collector (server/collectors/plaisio/collector.ts) executes in-process inside a standard Node.js Express backend hosted on Google Cloud Run in region europe-west2 (London, UK). There are no external scraping proxies, no Lambda functions, and no third-party feeds.
Dev vs. Production Deployment Status:
The application operates on Google Cloud Run service ais-dev-cnagud5zl6avrc35iycn6t (revision ais-dev-cnagud5zl6avrc35iycn6t-00004-mlj). The shared preview domain (ais-pre-...) is provisioned on Cloud Run in the same region but has not been deployed yet (returns Cloud Run 404). All historical collections and diagnostic probes were executed directly from the Cloud Run development service.
The Definitive Root Cause of Signalyn's HTTP 403:
Through forensic runtime experimentation on the active Cloud Run container, we executed side-by-side requests to Plaisio's origin:
Node.js legacy https.request (the transport used by Axios): Returned HTTP 403 Forbidden with Server: AkamaiGHost.
Node.js native fetch() (the Undici transport used by Pricelog): Returned HTTP 200 OK with Server: Vercel.
Plaisio's Akamai Bot Manager intercepts and blocks the TLS/HTTP client-hello fingerprint of Axios / Node's https module at the edge, while native fetch (with modern ALPN and Chrome 124 Sec-Fetch-* headers) passes through Akamai directly to Vercel origin. Signalyn can run this entirely inside its own Cloud Run backend by replacing its HTTP transport.

G. Can Signalyn Adopt the Same Architecture?
YES. 100% FEASIBLE.
Signalyn does not need external scraping services, residential proxies, or separate infrastructure. Signalyn can run the collection directly inside its existing Cloud Run backend service by aligning three specific technical factors with Pricelog:
Use Node.js Native fetch Instead of Axios:
Axios uses Node's legacy https module, which is fingerprinted and blocked by Akamai Bot Manager (Server: AkamaiGHost). Node.js 18+ native fetch uses Undici, which passes Akamai's TLS/ALPN inspection.
Apply Pricelog's Browser Impersonation Headers:
Include the full Sec-Ch-Ua, Sec-Fetch-*, Accept, and Accept-Language: el-GR headers on every request.
Scrape Public Category SSR HTML (/list/...):
Target Plaisio's public category pages rather than internal API routes, and parse the embedded #StructuredDataItemListB2C JSON-LD schema with Cheerio.
